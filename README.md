# AMD Constructions and Paint Services website

This is the updated static website prepared for the GitHub Pages repository `Amdconstructions.github.io`.

## Files
- `index.html` — page content, SEO metadata, and business structured data
- `styles.css` — responsive styling for desktop, tablet, and mobile
- `script.js` — mobile navigation, current footer year, and WhatsApp enquiry form
- `assets/amd-logo-final.png` — AMD logo
- `assets/amd-banner.webp` — AMD promotional banner
- `robots.txt` and `sitemap.xml` — search-engine discovery files

## Publish to GitHub Pages
1. Open the repository: https://github.com/Amdconstructions/Amdconstructions.github.io
2. Download or keep a backup of the current files before replacing anything.
3. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, `script.js`, `robots.txt`, `sitemap.xml`, and the `assets` folder at the root level; do not upload the enclosing folder itself as a nested folder.
4. Commit the changes directly to the `main` branch.
5. Wait for GitHub Pages to deploy, then open https://amdconstructions.github.io/ in a private/incognito window and hard-refresh if the old version appears.

## Contact form behavior
The enquiry form prepares a message and opens WhatsApp for the visitor to review and send. It does not silently send a message or store customer data on a server. This avoids presenting a static GitHub Pages form as if it had a backend.

## Before promoting the site
- Confirm `hello@amdconstructions.in` is an active mailbox before relying on it for customer enquiries.
- Check all phone, address, founder and company details.
- The project gallery uses illustrative external image references and explicitly says they are not completed AMD projects. Replace these with real approved project photos as they become available.
- External gallery and hero images are loaded from Unsplash and require an internet connection.
